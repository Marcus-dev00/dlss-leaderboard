# DLSS 人数登记排行榜

基于 **React + Vite + Supabase** 构建的现代、高颜值、支持多周期（总榜、月榜、周榜）的员工人数登记与实时排行榜系统。

## 🌟 功能特性

- 🏆 **三维榜单支持**：累计总榜、本月榜、本周榜毫秒级无缝切换。
- 🥇 **前三名领奖台 (Podium)**：冠军金色皇冠、亚军银色镀铬、季军铜色徽章高亮。
- ⚡ **Supabase Realtime**：数据更新全员实时广播同步，无需手动刷新。
- 🔑 **极简免邮箱认证**：姓名 + 密码直接登录，新员工首次登录自动静默注册。
- 📝 **快捷提交 & 撒花动效**：支持 `+1` ~ `+50` 快捷按键与自定义步进，提交成功弹出彩带庆祝。
- 📋 **明细与撤销历史**：员工可随时查看个人流水，支持误填时的快捷撤销。
- 📱 **多端自适应**：支持手机端、平板与电脑端高质感响应式展示。

## 🛠️ 技术选型

- **前端**：React 18 + Vite + TypeScript + Lucide Icons + Canvas Confetti
- **样式**：Vanilla CSS 原生高定制设计系统
- **后端/数据库**：Supabase (PostgreSQL + Auth + Realtime + RLS)

## 🚀 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 访问本地地址
# http://localhost:3000
```
